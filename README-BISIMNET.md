# BisimNet برای اندروید

نسخه‌ی برندشده‌ی کلاینت متن‌باز Mumla (مجوز GPLv3). **این پروژه هنوز کامپایل و روی گوشی تست نشده است.**
اولین بیلد را باید خودتان در Android Studio بگیرید؛ اگر خطایی آمد، متن کامل آن را بفرستید.

## تغییرهای انجام‌شده
- نام برنامه: BisimNet (در همه‌ی زبان‌ها) و شناسه‌ی برنامه: `ir.bisimnet.app`
- آیکون از لوگوی شما (آیکون Adaptive و آیکون‌های قدیمی) و رنگ‌های تم هماهنگ با لوگو
- حالت پیش‌فرض ارسال صدا: **دکمه‌ی فشار و صحبت (PTT)**
- امکان تعریف **سرور پیش‌فرض** که بار اول خودش به لیست اضافه می‌شود
- نسخه‌ی برنامه وقتی پوشه Git نیست روی `1.0.0` تنظیم می‌شود
- پوشه‌های fastlane و FUNDING (مخصوص پروژه‌ی اصلی) حذف شدند

## ساخت برنامه
1. نصب **Android Studio** و **JDK 21**، و از SDK Manager (با Show Package Details): Android SDK 36 و **NDK نسخه‌ی 25.1.8937393** (همین نسخه لازم است).
2. در ترمینال، داخل این پوشه: `./setup-native-deps.sh`
   (کتابخانه‌های صوتی Opus/Speex/CELT و SpongyCastle را دانلود می‌کند. بخشی از آن‌ها روی GitLab است و ممکن است به VPN نیاز داشته باشید.)
3. پوشه‌ی پروژه را در Android Studio باز کنید و صبر کنید Gradle همگام شود.
4. از Build Variants، گزینه‌ی **fossDebug** را انتخاب کنید (نسخه‌های goog و donation پیام حمایت مالی پروژه‌ی اصلی را نشان می‌دهند).
5. Build ← Build APK(s). برای انتشار: Build ← Generate Signed Bundle / APK با کلید امضای خودتان.
   نسخه‌ی release را فقط با fossRelease بسازید.

## تنظیم سرور پیش‌فرض
فایل `app/src/main/res/values/bisimnet_defaults.xml` را باز کنید و `bisimnet_server_host` (و در صورت نیاز پورت) را پر کنید.
این مقدار فقط برای کاربرانی اعمال می‌شود که برنامه را **برای اولین بار** نصب می‌کنند (برای تست، برنامه را پاک و دوباره نصب کنید).

## نکته‌های مهم
- **مجوز GPL:** اگر APK را به مشتری می‌دهید، باید کد منبع همین نسخه را هم در دسترس بگذارید (مثلاً یک مخزن GitHub و لینک در سایت) و فایل‌های `LICENSE` و `NOTICE-BISIMNET.md` و نام نویسندگان اصلی را نگه دارید. حذف نام آن‌ها از کد ممنوع است.
- نام پکیج داخلی کد همان `se.lublin.mumla` مانده تا ساخت پروژه خراب نشود. این بخش برای کاربر دیده نمی‌شود.
- مجوز میکروفون، سرویس پس‌زمینه و بلوتوث در Manifest از قبل تعریف شده‌اند؛ روی گوشی واقعی تست کنید.
- فایل `branding/playstore-icon-512.png` آیکون ۵۱۲ پیکسلی برای مارکت‌هاست.

## ساخت آنلاین (بدون نصب Android Studio)
فایل `.github/workflows/build-apk.yml` آماده است. یک مخزن GitHub بسازید، کل محتوای این پوشه را در آن آپلود کنید،
به تب **Actions** بروید، «Build BisimNet APK» را انتخاب و **Run workflow** را بزنید. بعد از چند دقیقه، فایل APK
در بخش Artifacts همان اجرا آماده‌ی دانلود است.
